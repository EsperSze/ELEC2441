Ending address of a memory block

Last address = starting address + block size in bytes − 1

Each byte has its own address. A block of N bytes begins at offset 0, so its last byte is at offset N − 1.

For memory sizes in these papers, 1 MB = 220 bytes and 1 GB = 230 bytes. The papers use $ to mark hexadecimal addresses.

2022 final · Q1(6)

A GPU has 4 GB of VRAM divided into four equal blocks of 1 GB each. The first block begins at $0000 0000. What is the address of its last byte?

  1. $01FF FFFF
  2. $02FF FFFF
  3. $04FF FFFF
  4. $3FFF FFFF
  5. $5FFF FFFF
Show worked answer

D. $3FFF FFFF

One block holds 1 GB = 230 bytes. Adding that size to the starting address gives $4000 0000, the first address of the next block. Subtract one byte to get $3FFF FFFF.

A. $001F FFFF

One block holds 2 MB = 2 × 220 = 221 bytes. Adding that size to the starting address gives $0020 0000, the first address of the next block. Subtract one byte to get $001F FFFF.
